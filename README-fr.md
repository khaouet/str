# Systèmes temps-réel (STR)

Supports du cours **Systèmes temps-réel**, en anglais *Real-Time Systems*.

## Contenu

- `1-Introduction.pptx` et `2-Concepts.pptx` : bases du cours
- `3-Ordonnancement.pptx` et `C2-ordonnancement*.pptx` : ordonnancement
- `Cours-STR.pdf` : support complet du cours
- `STR-TP-FreeRTOS/` : travaux pratiques FreeRTOS et exemples AVR
- `QCM_Systèmes_Temps_Réels_FreeRTOS_FormBuilder.txt` : questionnaire de révision
- `Systemes Temps ReelL3AII1_dc_L3-AII1.csv` : données du cours

L’organisation conserve les fichiers d’origine du cours et regroupe les
supports théoriques, les ressources sur l’ordonnancement et les travaux
pratiques dans le même dépôt.
