# Real-Time Systems (STR)

Course materials for **Systèmes temps-réel** (Real-Time Systems).

## Contents

- `1-Introduction.pptx`, `2-Concepts.pptx` - course foundations
- `3-Ordonnancement.pptx` and `C2-ordonnancement*.pptx` - scheduling
- `Cours-STR.pdf` - complete course reference
- `STR-TP-FreeRTOS/` - FreeRTOS practical work and AVR examples
- `QCM_Systèmes_Temps_Réels_FreeRTOS_FormBuilder.txt` - review quiz
- `Systemes Temps ReelL3AII1_dc_L3-AII1.csv` - course data

The repository is organized around the original course files so that lecture
material, scheduling references, and practical exercises remain together.
